# Website deployment

GitHub: https://github.com/mk-knight23/balto

The repository root contains `index.html`, so a Vercel static deployment can use the repository root. No build command or credentials are required. Alternatively enable GitHub Pages using Settings > Pages > Deploy from branch > main / root. Deployment must be tested before claiming a live URL.

Checks: white/gold palette, mobile layout, event count classifier, no secrets, no private hiring invite URL, no user data sent from the browser.
