# Balto Lab visitor guide

Updated 2026-11-05. Generated from the same pageGuides and glossary content used by the website (src/visitor-guides.ts). This guide is a dated snapshot; follow the current on-screen instructions if labels change.

Balto Lab is an independent educational and hiring demonstration by Kazi Musharraf, not an official Balto product. No real customer is contacted by the practice activities.

## Start here

Open the Start here page and choose a learning, practice or investigation activity. For a short introduction, choose Take a guided tour, then select the simulated call, supplied evidence or presentation. The navigation names below use plain language; each also identifies its technical title.

## Page help

Each page introduces its purpose, expected outcome and three things to try. Select a quick-start step or open Walk me through it for instructions and What to expect. Back and Next change the help step. Show this control scrolls to, highlights and focuses the relevant control; it does not click it, start a call, upload data or perform the action. If the target is not visible, follow the displayed instruction first and try again.

Use Show page help or Hide page help to choose whether the guide is shown. Open What is real, and what is a demo? for the page's accuracy boundary. Explain an unfamiliar word opens the local glossary. Back to Start here returns to the overview.

## Light, dark and motion preferences

Use the top-bar Dark or Light button to switch the current appearance. Open Display settings and choose Color theme: Use device setting, Light or Dark. Gentle visual effects can be disabled; the device's reduced-motion preference is respected. Display choices and the page-help preference are saved locally when browser storage is available. Analyzed logs remain in app memory and are cleared on reload; saving appearance does not persist incident evidence.

## Find your way

Use the sidebar to change pages. On a narrow screen, Open navigation opens the menu. Search workspace finds sections by name; Esc closes the search dialog. Each page can be opened using its URL fragment, listed below.

## Plain-language glossary

- **WebSocket:** A connection that stays open so an app and a server can exchange messages in both directions.

- **QA:** Quality assurance: reviewing a conversation against a set of checks. Here the checks use visible scripted phrases.

- **Synthetic:** Invented sample information made for learning. It does not describe real customers or business results.

- **Hypothesis:** A possible explanation to test. It is an idea, not a proven cause of a problem.

- **UTC:** A worldwide reference time. The bundled log has no timezone; treating its times as UTC is a convention, not a verified fact.

- **Copilot:** An assistant for preparing work for a person to review. This project's copilot uses fixed templates, not a connected AI model.

- **Log:** A text record of messages from an application. A line may describe an event or error without proving why it happened.

- **Evidence:** A source line or observation you can check. Evidence supports a statement; it may still leave the cause uncertain.
